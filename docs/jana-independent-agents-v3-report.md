# Jana: независимая проверка V3

17 октября 2026 года. Первый завершённый HTTP-прогон на 50 новых вопросах.

**Полный зачёт: 28/50 (56%).** Ещё 8 ответов частичные, 14 — ошибочные; все 22 считаются непройденными. На вопросах с ответом в базе полностью пройдено **16/30**, обнаружено **9/30 ложных отказов или ненужных уточнений**. Основные проблемы — пропущенные факты, ошибочный выбор намерения и недостаточные уточнения. Подлинные цитаты сами по себе эти ошибки не устраняют. Два независимых проверяющих оценили по 25 разных ответов; каждый ответ проверен одним из них.

Проверялся новый локальный читатель базы: Qwen3.5-9B Q4_K_M, файл около 6,17 ГБ, llama.cpp на `127.0.0.1:8081`, контекст 8192 токена и 20 слоёв на GPU. Модель получает вопрос и **все активные статьи**, за один смысловой проход выбирает намерение и ID фрагментов. Сервер проверяет ID текущего снимка, точность цитат и лимиты. FAQ-примеры в рабочий запрос не входят; дообучение весов не проводилось, платные API не используются. Устройство описано в [документации Jana](ai-jana-agent.md) и [архитектуре](architecture.md).

## Условия независимой проверки

Код, модель и параметры [зафиксированы](reports/jana-independent-agents-v3/runtime-freeze.json) до создания вопросов. Два новых агента с `fork_turns=none` подготовили по 25 вопросов, видя только [исходные статьи](reports/jana-independent-agents-v3/source-materials.json), без FAQ, старых вопросов, ответов и реализации. Это изоляция инструкциями, не отдельная песочница ОС. [Сравнение с 644 прежними формулировками](reports/jana-independent-agents-v3/novelty-check.json) не нашло точных повторов или поверхностного сходства ≥0,88; смысловые темы могли повторяться.

До inference в 15 случаях уточнены ожидаемые факты, чтобы не требовать незапрошенных сведений; сами вопросы не менялись. [Набор и gold](../knowledge_base/demo/independent_agents_v3.json) закреплены [отдельной фиксацией](reports/jana-independent-agents-v3/cases-freeze.json). По [протоколу](reports/jana-independent-agents-v3/protocol.json) полный зачёт требует всех запрошенных фактов без запрещённых утверждений и ошибочного понимания намерения; частичный ответ считается непройденным. Новые вопросы проходят один раз, без последующей настройки.

## Источники, API и отдельные проверки

Один HTTP-прогон завершил **50/50** запросов по цепочке `Vite:5173/api/v1 → FastAPI:8000 → Supabase`, с ролью `worker`; анонимный запрос получил **401**. Подлинность цитат и ссылок прошла **50/50** проверок. Все **11 активных статей** сверены до и после: состав и хеши содержимого совпали, `source_issues=[]`, `changed_inputs=[]`. Прогон только читал общую БД.

Время одного ответа: **p50 14,61 с; p95 24,88 с** (50 измерений `seconds`, p95 с линейной интерполяцией). Полный запуск с постпроверками занял **871,57 с**. Успешная проверка происхождения цитаты не подтверждает правильность её выбора для вопроса.

Это отдельно от качества смысла. До V3 разработка на уже известном V2 дала **38/50 полных ответов**, включая **26/30** вопросов с ответом в базе и **0 ложных отказов** на них ([ответы](reports/jana-independent-agents-v3/development-known-v2.json), [разбор](reports/jana-independent-agents-v3/development-known-v2-review.json)); это не слепой результат. [Проверка жизненного цикла знаний](reports/jana-independent-agents-v3/knowledge-lifecycle.json) прошла **3/3** сценария в памяти: новая статья, изменение факта и снятие с публикации.

Backend: **687 passed, 37 skipped**; пропущенным интеграционным проверкам нужен отдельный одноразовый PostgreSQL, а не общая Supabase. Frontend: **29 passed**, сборка прошла; после проверки UI-код не менялся. Эти проверки не являются оценкой 50 ответов Jana.

## Ограничения и воспроизводимость

Вопросы и оценки созданы агентами на небольшой вымышленной демонстрационной базе, а не реальными сотрудниками. Один конечный набор не гарантирует 100% правильности будущих ответов. История диалога не используется. При превышении вместимости всей базы возвращается **503 без обрезания статей**; масштабирование и массовая нагрузка этой проверкой не доказаны.

Для аудита доступны [протокол](reports/jana-independent-agents-v3/protocol.json), хеши [runtime](reports/jana-independent-agents-v3/runtime-freeze.json) и [набора](reports/jana-independent-agents-v3/cases-freeze.json), [HTTP-ответы и время](reports/jana-independent-agents-v3/http-first-run.json), [оценка A](reports/jana-independent-agents-v3/semantic-a.json) и [оценка B](reports/jana-independent-agents-v3/semantic-b.json). Runner — [`scripts/evaluate_jana_reader.py`](../scripts/evaluate_jana_reader.py), режим `http`, набор `knowledge_base/demo/independent_agents_v3.json`, соответствующий `--runtime-freeze` и новый путь `--output`. Повторный запуск будет повторной проверкой уже известного набора, а не новым слепым результатом.
