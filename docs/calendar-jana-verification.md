# Проверка календаря и Jana — 17 октября 2026

Из `origin/test` выборочно перенесены общий экспорт отпусков (8ae2748) и проверки публикаций локальной Jana. Изменения адаптированы к FSD и текущим слоям бэкенда; старая структура проекта и локальный стек ветки не объединялись целиком.

## Календарь

`GET /api/v1/requests/calendar.ics` выгружает согласованные отпуска с серверной проверкой прав. Поддерживает mine/team/all, диапазон дат и сотрудника. Выгрузка читает все страницы, сохраняет полные даты пересекающегося отпуска и отклоняет слишком большие выборки вместо незаметного обрезания.

Это ручной импорт ICS, не OAuth-подключение и не автоматическая синхронизация. Изменения и отмены после импорта нужно отражать в Google Calendar вручную. Импорт непосредственно в Google-аккаунт в этой проверке не выполнялся.

На реальном Supabase проверены вход и экспорт тестовых сотрудника, руководителя и HR: 9 сочетаний роли/области. Сотрудник получает 403 для команды; остальные разрешённые выгрузки возвращают корректный ICS. В файлах нет участников и комментариев, события имеют CLASS:PRIVATE и исключительную дату окончания. Производственные записи не изменялись.

Исправлена обработка ICS с query-параметрами: HTTP-клиент больше не пытается разобрать его как JSON. Браузерные сценарии скачивания, смены области и ошибки проходят на desktop и mobile 320 px.

## Jana

Основной чат выбирает провайдера через `JANA_PROVIDER=openai|local` (по умолчанию openai). Локальный режим требует работающего reader и актуальных проверенных публикаций. Источники снабжаются версиями; изменившаяся версия возвращает 409. Изменение базы во время обработки прерывает ответ. Docker-адрес reader разрешается только явной настройкой для jana-reader:8081.

На реальном API и Supabase прошли 30/30 вопросов контрольного корпуса: 16 ответов выдержками и 14 отказов. Это результат поиска и правил отказа, а не оценка генерации: OPENAI_API_KEY отсутствовал, локальная модель не установлена. Генерацию необходимо повторно проверить после настройки провайдера:

```powershell
.venv/Scripts/python.exe scripts/verify_jana_quality.py --require-generation
```

Флаг требует режим generated и предназначен для OpenAI; локальный reader выбирает подтверждённые выдержки (excerpts).

Проверки кода: полный запуск backend — 1017 passed, 134 skipped (БД-наборы без локального PostgreSQL); дополнительно после добавления тестов маршрутизации провайдера — 45 passed. Frontend: 42 unit tests, сборка и границы FSD прошли. 6 целевых браузерных сценариев прошли после исправления экспорта. Это браузерные проверки с подменённым API, отдельно от реальной проверки Supabase выше.
