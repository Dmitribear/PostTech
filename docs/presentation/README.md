# Материалы защиты PostTech

- `PostTech-defense.pptx`: 8 редактируемых слайдов с заметками выступающего.
- `PostTech-defense.pdf`: визуальная копия слайдов для просмотра без PowerPoint; текст в этой копии является частью изображения.
- `PostTech-backup.mp4`: резервный ролик, 2 минуты, без звука. Монтаж реальных экранов с подписями, а не непрерывная запись действий.
- `defense-script.md`: сценарий на 5:40 и ответы на вопросы.
- `assets/`: реальные экраны стенда с вымышленными персонажами.

Презентация проверена по структуре, геометрии и повторному импорту, все восемь слайдов просмотрены. Открытие в Microsoft PowerPoint не проверялось. Репетиция самого выступающего остаётся за вами: прочитайте сценарий вслух с таймером и сократите переходы между ролями при необходимости.

Запуск портала: `Start PostTech.cmd` в корне проекта. Приватные доступы: `.local/jury-access.html`. Пароли и ключи не входят в эти материалы. Подробнее: [памятка стенда](../jury-stand.md).
