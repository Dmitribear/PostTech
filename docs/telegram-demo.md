# Показ сайта и Telegram из main

Сайт и Telegram используют одну локальную базу, заявки, курсы и Jana.
**Запуск одной кнопкой теперь использует OpenAI API (`gpt-4o-mini`).**
Модель на ноутбук не скачивается. Нужны интернет и действующий API-ключ
с доступной квотой/балансом. Вопросы и опубликованные материалы базы знаний
передаются в OpenAI; ключ доступен только серверу, не браузеру и не боту.
Общая Supabase команды не изменяется.

## Первый запуск на ноутбуке друга (Windows)

1. Установите Docker Desktop с Linux-контейнерами и Git. При запросе Docker
   включите виртуализацию/WSL и перезагрузите ноутбук.
2. Скачайте проект:

   ```powershell
   git clone --branch main --single-branch https://github.com/Dmitribear/PostTech.git
   ```

   Если проект уже скачан, в его папке выполните `git pull --ff-only origin main`.
   Если Git сообщает о ваших незакоммиченных изменениях, сначала сохраните их.
3. В папке `PostTech` дважды нажмите **`Start Demo.cmd`**. При обычной установке
   он сам откроет Docker Desktop и подождёт готовности Linux engine.
4. При первом запуске вставьте **токен Telegram от BotFather**, затем
   **ключ OpenAI API** в соответствующие запросы окна и нажмите Enter.
   Символы скрыты — это нормально. При следующих запусках ввод не требуется.
5. Дождитесь открытия `http://127.0.0.1:8000`. Войдите обычной формой:
   `employee@posttech.demo`; пароль указан после `POSTTECH_DEMO_PASSWORD=`
   в файле `.local/docker.env` внутри папки проекта. Доступ к почте не нужен.
6. **Настройки → Telegram → Подключить Telegram**. Откройте свежую ссылку
   и нажмите Start. Если ссылка не передала код, скопируйте всю команду
   `/start <код>` из настроек и отправьте боту вручную. Дождитесь подтверждения.

При первом запуске скачиваются и собираются образы Docker, но **не 6,2 ГБ
модели Qwen**. Подготовьте всё заранее. Python и Node на ноутбук устанавливать
не нужно. После успешного запуска окно можно закрыть: контейнеры продолжают
работать. Не выключайте Docker/ноутбук и не допускайте сна во время показа.

Если запускаете того же бота, старый worker на другом компьютере должен быть
остановлен. Один токен — один запущенный экземпляр `telegram-bot`.

## Куда вставить или заменить ключи вручную

Файлы создаются при первом запуске. Откройте их Блокнотом, сохраните без
добавления расширения `.txt`, затем снова запустите `Start Demo.cmd`:

- `PostTech/.local/openai.env`: `OPENAI_API_KEY=ваш_ключ`, модель
  `OPENAI_MODEL=gpt-4o-mini` уже указана.
- `PostTech/.local/telegram.env`: `TELEGRAM_BOT_TOKEN=токен_от_BotFather`.
- `PostTech/.local/docker.env`: пароль обычного входа — `POSTTECH_DEMO_PASSWORD`.
  Не меняйте сгенерированные пароли существующей базы вручную.

Ключ OpenAI создаётся в [API Keys](https://platform.openai.com/api-keys).
[OpenAI рекомендует хранить ключ на сервере в переменной окружения](https://developers.openai.com/api/reference/overview).
Эти файлы исключены из Git и Docker build context: не добавляйте их в коммит
и не показывайте на проекторе. Launcher проверяет доступ к модели без генерации
ответа; это **не проверка баланса**. Перед показом задайте реальный вопрос Jana.

Данные нового ноутбука независимы от старого компьютера. Заявки, прогресс и
Telegram-привязки через GitHub не переносятся. Повторный запуск сохраняет
настройки и Docker volume. Не удаляйте volume. Старую базу из ветки `test`
с другой историей SQL нельзя автоматически подменять этой установкой `main`.

## Перед показом

1. Подключите питание и интернет, отключите автоматический сон на время показа.
2. Запустите `Start Demo.cmd`, войдите, проверьте `/profile` в боте.
3. Спросите Jana «Как оформить аванс?», откройте источник, проверьте отказ
   на отсутствующий в базе факт. Проверьте вопрос на сайте и в боте.
4. Заранее откройте разные браузеры для сотрудника, руководителя и HR.

Запуск из PowerShell (тот же облачный режим):

```powershell
powershell -ExecutionPolicy Bypass -File scripts/start_telegram.ps1 -Interactive -OpenBrowser
```

Локальная модель оставлена как **явная дополнительная опция**, она скачивает
около 6,2 ГБ: `scripts/start_telegram.ps1 -LocalModel -Interactive` (CPU) или
`-Gpu -Interactive` (настроенная NVIDIA). Скрипт `prepare_demo.ps1` проверяет
именно этот локальный режим с reader; для OpenAI он не требуется.

Для чата Telegram публичный адрес сайта не нужен. Сайт показывайте на ноутбуке,
бот — на телефоне. Для открытия всего портала внутри Telegram потребуется
доступный HTTPS-адрес той же установки и `PORTAL_PUBLIC_URL`.
Постоянная работа бота требует включённого компьютера/сервера: GitHub не хостит
этот backend, а `restart: unless-stopped` не включает выключенный ноутбук.

## Вход и точная привязка Telegram

Для локального стенда подготовлены аккаунты:

| Участник | Логин | Где удобно показывать |
| --- | --- | --- |
| Сотрудник | `employee@posttech.demo` | Сайт + личный Telegram |
| Руководитель | `manager@posttech.demo` | Другой браузер или отдельный профиль |
| HR | `hr@posttech.demo` | Ещё один отдельный профиль или режим инкогнито |
| Директор, если понадобится | `director@posttech.demo` | Отдельный профиль браузера |

Пароль этих аккаунтов — значение `POSTTECH_DEMO_PASSWORD` в приватном
`.local/docker.env`. Не пишите его в инструкцию и не демонстрируйте экран ввода
с раскрытым паролем. На сайте проверяйте имя и роль, прежде чем согласовывать.

В текущем `main` обычные вкладки одного профиля браузера разделяют вход.
Для одновременного показа разных ролей используйте разные браузеры/профили,
например Chrome для сотрудника, Edge для руководителя и Chrome инкогнито для HR.

1. Откройте локальный сайт на компьютере. Обычно это `http://127.0.0.1:8000`;
   точный адрес печатает launcher. Войдите по почте и паролю сотрудника.
2. Меню профиля справа вверху → **Настройки → Telegram**.
3. Если уже написано «Telegram подключён» и указан ваш аккаунт, ничего заново
   привязывать не нужно. Проверьте переключатель уведомлений.
4. Если связи нет, нажмите **«Подключить Telegram»**. Откройте новую личную ссылку,
   затем нажмите **Start/Старт** в чате с ботом. Ссылка одноразовая, действует
   10 минут и не должна пересылаться другим людям.
5. Если ссылка открыла только чат, скопируйте на сайте **всю запасную команду**
   из поля под пояснением «Если кнопка не сработала…»: `/start <личный код>`.
   Отправьте её целиком этому боту. `<личный код>` — обозначение: не набирайте
   эти слова и не отправляйте один `/start` без кода. При запрете буфера обмена
   выделите команду в поле и скопируйте вручную.
6. Дождитесь сообщения **«Аккаунт связан с сайтом»** и меню бота. На сайте нажмите
   **«Обновить статус»** — должно появиться **«Telegram подключён»**. В боте
   отправьте `/profile` и сравните профиль с сайтом.

На текущем компьютере переход по ссылке не всегда передавал код в Telegram;
полная команда из шага 5 успешно подключила аккаунт. Это однократная операция:
после подключения достаточно открыть `@JanaMenHr_bot` и отправить `/menu`.

Один аккаунт сотрудника связан с одним Telegram, и один Telegram — с одним
аккаунтом сотрудника. На показе не переключайте один Telegram между сотрудником,
руководителем и HR: это требует отключения и новой привязки, а старые кнопки
перестают подходить. Руководителя и HR удобнее показывать на сайте. Если друзья
хотят использовать их роли именно в боте, заранее привяжите **их отдельные
Telegram-аккаунты** к соответствующим аккаунтам сайта.

После привязки отправляются новые уведомления; старые события автоматически
не рассылаются. Не используйте `/stop` и «Отключить Telegram» до окончания
показа. Это действительно удаляет связь, а не просто закрывает меню.

## Сценарий на 10 минут

Сначала прогоните его один раз заранее и измерьте время на этом компьютере.
Уточните у команды, что показанные профили, регламенты и суммы — **демонстрационные
данные**. Выберите незавершённый курс и уже согласованный отпуск для `.ics`.
Все новые демонстрационные заявки помечайте комментарием `DEMO JURY` и датой.

| Время | Действие | Что объяснить жюри |
| --- | --- | --- |
| 0:00–1:00 | На сайте открыть профиль сотрудника; в боте `/profile` | «Сайт и Telegram показывают один аккаунт из общей базы, а не два набора данных». |
| 1:00–2:00 | `/courses` → назначенный курс → урок. Прочитать и нажать «Я изучил(а) урок»; обновить курс на сайте | «Материал и прогресс общие». Если курс уже завершён, показать существующий результат, а не обнулять его. |
| 2:00–3:00 | `/menu` → «Аванс» → `100` → комментарий `DEMO JURY <дата>` → «Подтвердить». Открыть эту заявку на сайте | «Действие сохраняется только после подтверждения, запись сразу видна в другом интерфейсе». |
| 3:00–4:30 | Руководитель на сайте согласует эту заявку; HR окончательно одобряет. На телефоне показать уведомления, в `/requests` открыть карточку и «Обновить» | «Сначала руководитель, затем HR. Состояние одинаковое на сайте и в боте». Аванс демонстрационный, реальную выплату система здесь не выполняет. |
| 4:30–5:00 | В боте `/calendar` или карточка уже согласованного **отпуска** → «Скачать .ics» | «Файл содержит доступные согласованные отпуска и импортируется в Google Calendar вручную». Аванс в календарь не попадает. |
| 5:00–7:00 | `/ask Кто окончательно одобряет отпуск?` → дождаться ответа → открыть кнопку «Источник» | «Jana через OpenAI выбирает фрагменты опубликованной базы; сервер проверяет цитаты и источники». |
| 7:00–8:30 | `/ask Какой пароль у Wi-Fi в офисе JanaPost?` | «Если подтверждённого факта нет в базе, Jana сообщает об отсутствии ответа и предлагает уточнение/HR». Перед показом убедитесь, что такого факта действительно нет в текущей базе. |
| 8:30–10:00 | Показать схему общей системы и ответить на вопросы | «Один backend, одна база, роли и история действий. Google Calendar пока через файл; постоянная доступность требует работающего сервера». |

Отметка урока и подтверждение заявки **меняют локальные демо-данные**. Launcher
их сам не создаёт. Для повторного показа не нажимайте подтверждение уже выполненной
операции: открывайте свежую карточку через `/menu`, проверяйте историю и используйте
новую помеченную заявку только если она действительно нужна для демонстрации.

Jana может отвечать дольше отведённого окна. Пока она работает, не отправляйте
этому же Telegram-пользователю новый вопрос и не нажимайте подряд другие действия:
бот попросит дождаться предыдущего запроса. В это время расскажите про архитектуру
на сайте или презентации. Если укладываться в 10 минут не получается, покажите
заранее сохранённый результат **с явной пометкой «предыдущий прогон»**, а живой
ответ откройте, когда он придёт. Не выдавайте запись за ответ текущего запроса.

Импорт `.ics` в Google лучше подготовить до выступления в отдельный тестовый
календарь. На сцене достаточно показать файл и ранее проверенные даты: повторный
импорт может создать дубликаты, автоматической синхронизации пока нет.

## Если что-то пошло не так

| Симптом | Что сделать |
| --- | --- |
| Бот молчит | Проверить питание/интернет и контейнеры. Убедиться, что запущен один `telegram-bot`. Не запускать второй worker и не вызывать `getUpdates` вручную. |
| «Свяжите аккаунт» после `/start` | Открыть настройки сайта и отправить полную свежую команду с кодом; затем обновить статус. |
| Ссылка истекла/использована | Если сайт уже показывает подключение — `/menu`. Если связи нет — создать новую ссылку на сайте. |
| Старая кнопка не работает | `/menu` и заново открыть нужную заявку/курс. Черновики истекают через 15 минут и теряются при перезапуске worker; сохранённые данные остаются в БД. |
| Ошибка OpenAI / нет ответа Jana | Проверьте ключ, доступ к модели и баланс API. После замены ключа повторите запуск кнопкой. |
| Сервисы запущены, но Jana не отвечает | Проверьте интернет и реальный вопрос. Доступ к модели при запуске не гарантирует достаточную квоту генерации. |
| Нет уведомления | Проверить привязку и включённые уведомления. Смотреть новую заявку и её статус на сайте; старые события после подключения не рассылаются. Не создавать дубликат заявки ради повторного уведомления. |
| Телефон не открывает сайт | Локальный URL не доступен с телефона. Использовать чат бота и сайт на компьютере либо заранее настроенный HTTPS этой же установки. |

Статус контейнеров облачного режима:

```powershell
docker compose --env-file .local/docker.env --env-file .local/telegram.env --env-file .local/openai.env -f compose.demo.yaml -f compose.telegram.yaml -f compose.openai.yaml ps
```

Во время выступления не запускайте `down`, не удаляйте volumes и не публикуйте
`docker compose config` — он раскрывает секреты. Закрытие вкладки браузера
само по себе бота не останавливает.
